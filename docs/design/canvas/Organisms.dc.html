el organismo que no dibuja nada
Un when exhaustivo sobre el estado sellado. Existe para que ninguna pantalla vuelva a escribir if (isLoading): si mañana aparece un quinto estado, el compilador señala cada lugar que hay que actualizar.

Room emite siempre; la red solo actualiza la tabla. fromCache es «hubo lista pero la red falló».

Respuesta correcta con lista vacía, o filtro sin coincidencias. No es un error.

FsStateBlock (error + reintentar)
AppError del kernel, mapeado a un texto en la capa de UI. Solo cuando la caché también está vacía.
LA COMBINACION
El caso que el desafío realmente pone a prueba es Content + fromCache: hay datos que mostrar y algo salió mal. Un estado sellado plano no lo puede expresar, por eso fromCache viaja como campo dentro de Content y no como una quinta rama. Error y contenido conviven; error y esqueleto nunca.
